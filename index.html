Under the hood

From a voice note to a resolved ticket.

The shape of a production WhatsApp agent, as I build them. Hover or tap a step.

  1. 01

    Webhook in

    Meta Cloud API or Twilio posts the message. Signatures are verified, duplicates dropped, rate limits applied.

  2. 02

    Transcribe

    Voice notes go through Groq Whisper. Hindi, English and Hinglish are all fair game.

  3. 03

    Understand

    A LangGraph state machine detects language and classifies one of 10 intents: order status, refund, exchange, payment issue, FAQ and more.

  4. 04

    Act

    An adapter layer talks to the store's systems. RAG answers from the brand's own knowledge. Circuit breakers fall back between LLM providers.

  5. 05

    Reply or hand off

    The answer goes back on WhatsApp; anything unclear is escalated to a human with the full context. An ops dashboard keeps threads visible.

  • Tested: automated test suites run in GitHub Actions CI
  • Observable: logs, retries and an ops dashboard, not a black box
  • Deployable: Docker, Railway / Render / Vercel, runbooks included

FAQ

Before you write to me.

How does a project start?

You send a short description on WhatsApp or the form below. I reply within a day with questions or a rough plan, then send a written scope, timeline and fixed quote. Work begins after the first payment.

How do we communicate while you build?

Async-first: a shared channel, short written updates and a working preview link so you can see progress rather than read about it. Calls are fine when they help.

Do I own the code?

Yes. On final payment the repository, deployment access and documentation are handed over to you.

What if the AI gets something wrong?

I design for that: tests, fallbacks between LLM providers, confidence checks and a clean human handoff path, so unusual cases reach a person instead of a wrong answer.

Do you take part-time or hourly work?

Yes — contract and part-time engagements are welcome, especially for teams who need an extra full-stack or AI engineer for a few weeks.
